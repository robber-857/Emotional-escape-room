# 当前版本事件与提示词对照

整理日期：2026-10-06。提交基准：本机 3003 当前展示效果及对应的 `Eltondev` 工作区源码。已通过 HTTP 返回的生产 JS、CSS 和图片核对本次变更的主要文案、样式与素材。

这里的“提示词”指玩家看到的事件问题、操作说明和反馈文案。以下直接保留源码原文；**粗体为主提示**，辅助说明和按钮写在同一格。未单独弹窗的事件明确标注。
