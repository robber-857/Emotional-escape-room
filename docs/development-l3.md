## 当前交互

L3-01 有打开门、关门、坐稳等待、拉开右窗帘、关闭左窗、关闭风扇电源六组是/否。关门必须先开门；仅明确关门后才出现风暴与其余四组交互。关门触发短暂轻微震动；系统减少动态效果和菜单开关均可禁用，无连续强闪烁。

关闭气泡不记录拒绝。选择否后仍可重新选择是；相同选择不重复记录，已经执行的是不反向撤销。等待只记录选择，不设持续时间、不自动停止风暴，也不锁住其他控件。这些是便于 review 的前端交互约定，最终行为去重和规则发布由后端批次确认。

L3-02 九种物品完整提供：围巾、小灯笼、雨伞、指南针、小玩偶、钥匙、日记本、登山绳、背包。先确认是否携带；是进入物品选择，预选可更改，二次确认后只保留一件；否则记录不带并停止选择。确认后只能通过明确重置当前预览片段重新选择。携带是与物品确认分别有事件；草稿单独标注，不生成分数。`scoring.status=pending_configuration`、`contributions=null`，没有零分替代。

本机每次成功写入后才更新 UI，拒绝写入不显示成功；存档按事件重放验证，损坏时保留原值并阻止继续覆盖。多标签变更提示读取最新，写入前再比较存储值；这是本地冲突防护，不是服务器事务或分布式锁。记录上限 400，满额显式阻止操作，可查看记录或确认重置。菜单暂停交互、原生 dialog 管理焦点；触屏竖屏提示不能用 Escape 绕过。
