# 第二幕：半开的门（三种互斥结果）

2026-10-02，按用户确认的评分表实现。仅适用于新旅程绑定的 `event-scores-v7-l2-explore`，结算规则为 `first-entry-or-l2-exit-v1`。

| 结果 | V | T | A / F | 结算时机 |
| --- | --- | --- | --- | --- |
| 直接进入 | -2 | +1 | null / null | 开锁后首次选择进入，此前没有明确选择不进入 |
| 先不进入，后来进入 | 0 | -2 | null / null | 曾明确选择不进入，之后首次进入 |
| 不进入，留在大厅 | +2 | +1 | null / null | 门已打开、始终未进入，进入第三幕时结算 |

三个结果共用 `l2.explore` 账本组，每个旅程最多一条。明确点“否”只保存事件，不提前计分；关闭提示不制造“否”。第一次进入后结果固定，返回大厅、再次进入、重复请求均不重复计分。门未打开就从家具出口离开，不产生本组评分。V=0 是明确的零分测量，A/F=null 表示不测量；不叠加旧的“进入黑暗空间探索 A-1”。本规则与第三幕风暴的门事件分别结算。

服务器从已接受事件历史读取进入/拒绝顺序，刷新不会丢失。进入第三幕时的结算与第三幕启动处于同一事务，之后第二幕动作拒绝修改。已有旅程按创建时冻结的策略继续运行，不补算本次新分值，也不改写历史回执。

实现入口：`apps/api/app/score_rules.py`、`score_service.py`、`config/event-scores.json`；评分面板显示中文事件名及等待离幕结算的原因。
