## 当前存档与代码边界

L3 无 API、无服务器凭据读取、无正式评分/结果/报告。入口 `/l3?preview=1`，物品段 `?preview=1&segment=carry`；正常流程加 `from=storm`。不带 preview 参数的 `/l3` 有明确门禁提示。独立物品预览入口仍保留供开发查看。

- 本机键：`emotional:l3:preview:v1:storm` 和 `emotional:l3:preview:v1:carry`。
- JSON：version=1、source=local_preview、segment、events。事件字段 id/at/action；action 为 decision(slot,yes)、carry(yes)、draft(item)、confirm。
- `apps/web/src/features/l3/model.ts`：transition、restore、stormComplete、isRepeatedDecision。`L3Game.tsx`：保存成功后跳转、存储错误、多页冲突、重开确认。`Scene.tsx` / `CarryScene.tsx` / `Television.tsx`：场景。
- `apps/api/app/l2_api.py`、l2_domain.py、l2_receipts.py 可参考鉴权、前置关卡、事务、期望版本、action_id 幂等和真实回执模式。评分入口 `scoring.py` 当前只保留事实与待配置状态。
